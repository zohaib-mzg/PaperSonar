## Versioning

The Phase 1 files are a design record. Ongoing implementation documentation can evolve in Markdown. Record material changes to the corpus, model, or counting rules as a new decision and preserve the prior evidence before publishing a new report version.

When changing a Word report, regenerate its PDF and check the rendered pages. Update the DBML, SQL, dictionary, and diagrams together when changing the physical model.
